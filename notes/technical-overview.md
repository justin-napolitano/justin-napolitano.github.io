This repo is where I host my personal website, built with Python and Sphinx. It acts as my portfolio and project showcase.

## Key Features

- Static site generation using Sphinx
- Blog content and documentation management
- Compatible with modern static site tools

## Tech Stack

- Python
- Sphinx for documentation
- Makefile and batch scripts for building
- Docker is assumed for some components

## Quick Start

1. Clone the repo:

    ```bash
    git clone https://github.com/justin-napolitano/justin-napolitano.github.io.git
    cd justin-napolitano.github.io
    ```

2. Install Sphinx:

    ```bash
    pip install sphinx
    ```

3. Build the site:

    ```bash
    make html
    ```

   On Windows, run:

    ```bat
    make.bat html
    ```

The generated site can be found in the `docs` directory.

This project's ongoing. Future plans include adding more content and improving responsiveness.
